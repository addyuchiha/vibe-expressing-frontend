# Vibe Express

Vibe Express is a SaaS web application that visualizes and monetizes awkward silences and cringe moments during calls. 

## Features

- **Landing Page**: Engaging tagline and a clear call-to-action to start capturing vibes.
- **Dashboard**: A comprehensive view of live sessions, cringe scores, and monetization stats.
- **Authentication**: Secure login and signup using JWT with form validation.
- **Billing**: Manage your subscription plans and usage statistics.

## Tech Stack

- **Frontend**: React
- **Styling**: Tailwind CSS
- **Routing**: React Router
- **State Management**: Context API

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/vibe-express.git
   ```
2. Navigate to the project directory:
   ```
   cd vibe-express
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Start the development server:
   ```
   npm start
   ```
